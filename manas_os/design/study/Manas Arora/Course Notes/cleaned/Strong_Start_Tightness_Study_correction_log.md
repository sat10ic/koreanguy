## Book-build caution

This source should feed the Strong Start / timing chapter as a core supporting study.

It should not be reduced to “tight previous day good.” The value is more precise:

- member-submitted wins reduce hindsight bias;
- prior-day tightness appeared in more than 80% of the sampled winners;
- one working trade can still be invalid if it teaches a bad habit;
- no fixed tightness number is given;
- the trader must visually compare the latest candle to the stock’s own recent bars;
- contraction matters because expansion often follows, especially when prior momentum was upward.
