# TraderLog v2 — Execution Plan

**Goal:** turn the v1 pipeline (mostly built) into a working *brain and engine*:
a reliable, self-running pipeline feeding clean, insightful, tested surfaces —
no stale Ledgers, no empty Traders, no missing stock analytics, no dead tabs.

**Baseline state (measured 2026-08-25, commit a1f50878):** 3,395 real posts,
100% classified; 1,274 vision transcriptions; 94 positions / 110 events; insight
tables (39/284/549); trader_style 17 rows; activity signals 535,991; tape returns
live on Radar; Ledger lenses + R badge + regime analytics; run_recon.py
orchestrator; Telegram outbox (dry_run); XP fixed (C8). Known v1 failures the
user flagged: Ledger stale/incomplete, Traders empty-feeling, Market outdated,
Feed ugly/no insight, Symbol page + lightweight-charts missing, Library useless,
no stock-level analytics visible.

## Phase A — Pipeline hardening (the engine must never go stale)

A1. **Reconcile completion** — resume `python traderlog/run_recon.py --yes` on a
    live pool window; ~293 remaining roots; idempotent. Done-test: 0
    unreconciled roots with stated numbers; newest trade threads land in Ledger.
A2. **Nightly loop wiring** — `run_recon.py` scheduled (Task Scheduler entry
    documented in HANDOFF), plus a `FRESHNESS` policy: checks surface stale
    post/derived ages instead of passing silently.
A3. **Provenance policy** — maintainer decision recorded: audit-label
    provenance (apply_verified_*) accepted as sufficient vs provider-run
    provenance; NULL-run_id rows either re-run via provider when the pool
    recovers or the C7 entry closes as accepted.
A4. **Dead-code declutter** — remove rolled-back legacy screens/files, seed_mock
    stays disposable-only, scratch inventory zero.

## Execution mechanics
- Agents per phase with disjoint file ownership; orchestrator verifies every
  claim personally (tests + spot-checks against source data).
- Rate-window awareness: LLM stages gated on pool health probes; the
  orchestrator cools down instead of thrashing (proven this session).
- Nothing committed until the maintainer QCs.

## Kill conditions
- If a surface cannot show cited evidence for every number it prints, it ships
  an empty state, not a fake metric.
- If the free provider pool stays exhausted for >24h, LLM stages pause; the
  agentic audited paths (apply_verified_*) carry the wave instead.
